# P0-1.1 Fix Summary — Option Chain Silent Error Swallowing

**Date:** 2026-08-12
**Status:** Implemented, tested

## Root Cause

Two-layer silent error propagation:
1. **Adapter layer** (`data_adapter.py:442-444`): Caught ALL `FyersError` and returned `{}`, swallowing `FyersDataEntitlementError` and `FyersTokenExpired` that should propagate.
2. **Router layer** (`intelligence_router.py:188-189`): Converted non-ok responses to `return [], None`, making the option chain appear completely blank with no error message.

## Changes Made

### File 1: `src/shettyxtreme/integration/fyers/data_adapter.py`

**Lines 442-450** — Added specific except clauses BEFORE the generic `FyersError` catch:
- `FyersDataEntitlementError` → logs error, re-raises
- `FyersTokenExpired` → logs warning, re-raises
- `FyersError` (generic) → logs warning, returns `{}` (unchanged behavior for non-critical errors)

No new imports needed — `FyersDataEntitlementError` and `FyersTokenExpired` were already imported at lines 45, 48.

### File 2: `src/shettyxtreme/terminal/api/intelligence_router.py`

**Lines 188-193** — Replaced silent `return [], None` with proper error surfacing:
- Code `-373` → raises `DataEntitlementError` (same as the `entitlement` flag path)
- Any other non-ok → raises `HTTPException(503)` with code and message in detail

No new imports needed — `HTTPException` was already imported at line 12.

### File 3: `tests/integration/test_fyers_data_adapter.py`

Added 5 new tests to `TestOptionChain`:
1. `test_entitlement_error_propagates` — `FyersDataEntitlementError` is raised, not swallowed
2. `test_token_expired_propagates` — `FyersTokenExpired` is raised, not swallowed
3. `test_generic_fyers_error_returns_empty` — generic `FyersError` still returns `{}`
4. `test_empty_expiry_omits_timestamp_param` — regression: empty string expiry → no `timestamp=` in URL
5. `test_none_expiry_omits_timestamp_param` — regression: None expiry → no `timestamp=` in URL

### File 4: `tests/terminal/test_options_chain_prime.py`

Added `TestFetchChainWithSpot` class with 6 tests:
1. `test_entitlement_code_minus_373_raises_data_entitlement` — code -373 → `DataEntitlementError`
2. `test_entitlement_flag_raises_data_entitlement` — `entitlement: true` → `DataEntitlementError`
3. `test_generic_error_raises_503` — arbitrary error code → `HTTPException(503)`
4. `test_error_without_code_or_message_raises_503` — bare error → `HTTPException(503)`
5. `test_ok_response_returns_chain_and_spot` — legitimate ok → returns chain + spot
6. `test_ok_empty_chain_returns_empty_list` — ok with empty chain → returns `([], None)`
