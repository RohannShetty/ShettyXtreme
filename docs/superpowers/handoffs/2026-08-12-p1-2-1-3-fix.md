## Known Limitations

- `market_router.py` still uses the old `_INDEX_SYMBOLS`-or-else-EQUITY shortcut for `_resolve_symbol`. The watchlist router is fully hardened; market_router can be updated in a follow-up.
- The natural contract parser (`/api/symbols/resolve`) handles "NIFTY 24K CE" style queries but doesn't yet auto-commit to the chain grid — the user must select from the search dropdown.
- `_publish_market_tick` is stored on `app.state` only after `init_terminal_adapters` runs (needs a valid Fyers token). Without a token, dynamic subscribe degrades gracefully (logged, no crash).
