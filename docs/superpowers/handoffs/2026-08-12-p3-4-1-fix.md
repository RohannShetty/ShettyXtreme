# P3-4.1 Handoff — Paper Trading Must Feel Real

**Date:** 2026-08-12
**Status:** ✅ Complete — all tests pass, all checks green

---

## Summary

Paper trading in ShettyXtreme is no longer a deterministic, cost-free simulator. Five realism
models are injected into `PaperTradingEngine` via optional, configurable policy objects — when
None the engine behaves identically to the pre-P3-4.1 deterministic simulator.

## What was implemented

### 1. Slippage model (`SlippageModel`)
- **Spread-based**: BUY fills at ask, SELL fills at bid + residual 2 bps (when bid/ask available from Fyers)
- **Fixed bps fallback**: MARKET 5 bps, LIMIT 2 bps (when no spread)
- **Volume-based add-on**: +1 bps per 10% of tick volume exceeded
- Configurable via constructor args

### 2. India-correct fees model (`FeesModel`)
- **Brokerage**: ₹20 per order OR 0.03% of notional, whichever is lower
- **STT**: 0.01% on options, 0.1% on equity sell
- **Exchange charges**: NSE 0.05% (options), BSE 0.01% (equity)
- **GST**: 18% on (brokerage + exchange + SEBI)
- **SEBI**: ₹10 per crore (0.0001%)
- **Stamp duty**: 0.003% options buy, 0.015% equity delivery buy
- Fees deducted from capital at fill time, tracked per-fill on `Fill.fees`

### 3. Probabilistic limit fills (`FillProbabilityModel`)
- Distance-based: `fill_prob = exp(-distance_bps / 10)`
- Time-in-market: after 5 ticks, +10% per tick
- Partial fills: order qty > 10% of tick volume → fill 50-80% randomly
- Gap-through cancellation: BUY limit cancelled if LTP > limit, SELL if LTP < limit

### 4. Engine-side margin sizing (`MarginPolicy`)
- MIS equity: 20% of notional
- CNC delivery: 100% of notional
- Derivatives buy: 100% of notional (full premium)
- Derivatives sell: 110% of notional (premium + 10% buffer)
- Rejects before filling if `available < required`

### 5. Fixed realized P&L
- `get_pnl()` now sums `pos.pnl` (which accumulates on position close) instead of the dead `Fill.pnl` (which didn't exist)
- `total_fees` field added to P&L summary
- Capital accounting: BUY debits notional + fees, SELL credits notional - fees

## Configuration surface

```yaml
# configs/default.yaml
paper_trading:
  slippage_model: "layered"    # "layered" | "none"
  fees_model: "india"          # "india" | "none"
  fill_probability: true       # true | false
  margin_check: true           # true | false
  slippage_bps_market: 5       # fixed bps for MARKET when spread unavailable
  slippage_bps_limit: 2        # fixed bps for LIMIT when spread unavailable
```

All models are optional (default None) — existing code that constructs `PaperTradingEngine()`
without args gets the pre-P3-4.1 deterministic behavior.

## Architecture notes

- Models are stateless; mutable state (bid/ask/volume caches, tick counters, total_fees) lives
  in the engine
- Event shapes (`ORDER_FILLED`, `POSITION_CHANGED`) unchanged — ledger, projections, UI keep working
- `Fill.fees` defaults to 0.0 — existing code constructing Fill without fees is unaffected
- The `paper_realism.py` module has zero engine imports — pure computation, fully unit-testable
