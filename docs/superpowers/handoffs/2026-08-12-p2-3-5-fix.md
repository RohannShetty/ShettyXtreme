## Architecture

```
[TechnicalAnalyst] [OptionsAnalyst] [SentimentAnalyst]
         ↓                ↓                ↓
         └────────┬────────┘────────────────┘
                  ↓
           [RiskManager]  ← annotates with risk rules
                  ↓
        [PortfolioManager]  ← weighted aggregation
                  ↓
          [Final Proposal]  → operator decides
```

## Key Design Decisions

1. **Agent abstraction**: `Agent` dataclass with `compute()` method, registered in `AGENTS` dict (mirrors `LENSES`)
2. **D3 compliance**: All deterministic agents are pure Python — zero LLM calls, zero external deps
3. **Risk is read-only**: RiskManager annotates signals with risk rule outcomes but never gates live orders
4. **Portfolio is deterministic**: Weighted voting over analyst signals; LLM narration is optional
5. **Knowledge store**: `kind="agent_signal"` at `proposed` status (human activation gate preserved)
6. **Scheduler**: Dual-cadence — agents at 5 min (zero cost), lenses at 60 min (LLM cost)
