## What was implemented

### 1. Backend: `PortfolioRiskAggregator` (new module)

**File:** `src/shettyxtreme/intelligence/risk/portfolio_risk.py`

Pure, EventBus-agnostic aggregator computing all 4 risk heat map dimensions from inputs `{positions, instrument_master, spot_map, iv_map, margin}`:

1. **Enrichment pass** — resolves option metadata via `from_fyers()` parser + instrument master lookup (strike/expiry/option_type/lot_size/instrument_type). Positions without resolution degrade to "Unknown" buckets — never fake zeros (honesty rule).

2. **Sectoral exposure** — groups `net_quantity × buy_avg` notional by sector via curated `SYMBOL_SECTOR` map; outputs per-sector `{sector, notional, pnl, share_pct}` sorted descending.

3. **Greeks concentration** — per option position, `unit_greek × net_quantity × lot_size` via `GreeksCalculator`; sums across book → `{delta, gamma, theta, vega}` with long/short breakdown; flags lopsided profiles (e.g. `|theta| >> |vega|`).

4. **Max-loss scenario** — for shifts in `{-10%, -5%, +5%, +10%}`: option legs repriced via Black-76 at shifted spot; futures/equity legs via `Δspot × net_quantity`. Reports worst case + per-scenario P&L.

5. **Margin utilization** — `margin_used` from `get_margin()["utilized"]`, `margin_available` as today; emits `utilization_pct` + breach state.

### 2. Sector Map (new module)

### 4. New API Endpoint

**File:** `src/shettyxtreme/terminal/api/execution_router.py`

- `GET /api/execution/risk/heatmap` → `RiskHeatmapResponse`
- Calls `PortfolioRiskAggregator.compute()` with live data from:
  - `PositionProjection` (positions)
  - `WatchlistProjection` (spot prices)
  - `_iv_cache` (IV map from chain enrichment)
  - `RiskProjection` (margin data)
  - `instrument_master` from `app.state` (dependency injection)

### 5. Response Models

**File:** `src/shettyxtreme/terminal/api/models.py`

New models:
- `SectorExposureItem` — sector, notional, pnl, share_pct
- `GreekBreakdownItem` — long_val, short_val, net
- `GreeksConcentrationItem` — delta/gamma/theta/vega breakdown + lopsided_warning
- `ScenarioPnlItem` — shift_pct, total_pnl
- `StressItem` — scenarios list, worst_case_pnl, worst_case_shift
- `MarginUtilizationItem` — margin_used, margin_available, total, utilization_pct, breach
- `RiskHeatmapResponse` — all 4 dimensions + position_count + enriched_count

**Extended `PositionResponse`** with `instrument_type` field (OPTION/FUTURES/EQUITY/INDEX).

### 6. Frontend: `RiskHeatmap.svelte` (new component)

**File:** `src/shettyxtreme/terminal/web/src/components/RiskHeatmap.svelte`

Mounted in `App.svelte` bottom strip alongside `PositionsRiskStrip`. Renders 4 blocks:

1. **Sector grid** — heat cells (sector × notional share), intensity scaled by `share_pct`; colored by P&L sign per DESIGN.md red/green convention.
2. **Greeks bar** — delta/gamma/theta/vega magnitudes, long vs short split (bar chart).
3. **Stress table** — rows `-10% / -5% / +5% / +10%`, worst-case highlighted with danger styling.
4. **Margin gauge** — reuses existing bar/chip pattern from `PositionsRiskStrip.svelte`.

All plain CSS/SVG (no chart lib — repo convention). Reuses `ScrollArea`, `EmptyState`, `LoadingState`, `ErrorState` primitives.

- **Honesty rule:** unknown margin/sector/greeks → `None`/empty, never fabricated zeros.
- **OBSERVER-first (D10):** heat map is read-only analytics.
- **No new deps:** greeks/stress math is pure Python + stdlib.
- **DESIGN.md compliance:** red=up `#f6525c`, green=down `#2ebd85`, warning `#ffb020`, danger `#e5484d`. All numerals in mono face with tabular figures.
