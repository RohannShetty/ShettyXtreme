# Section 11 — Dhan Integration (ARCHIVED)

> **ARCHIVED 2026-08-05 — superseded by [Section 11 — Fyers Integration](11-fyers-integration.md).** This section documented the Dhan-era integration (D8, ADR-007). Dhan was replaced by Fyers as the primary broker per [ADR-008](../decisions/ADR-008-fyers-migration.md); `integration/dhan/` and `auth/dhan_oauth.py` were deleted, and `src/` is Dhan-free. This file is kept only for history — the live broker section is **11-fyers-integration.md**.
>
> Summary of the archived Dhan stances (superseded): single-primary `DhanContext(client_id, access_token)` credential model with an optional PIN/TOTP `data_access_token` fallback; DhanHQ-py pinned 2.2.0; WS v2 subscription codes 15/17/21; error 806 = data entitlement; 807 = token expired (silent renew); postback webhooks for order updates. The Fyers migration re-mapped 806 → HTTP 403/-373, replaced postbacks with the JSON order WebSocket, and removed the PIN/TOTP fallback in favor of daily OAuth2 authorization-code re-auth.
